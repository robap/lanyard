Criterion 9 — a logout is not silently undone by a renew
==============================================================================

  after mgr.signoutRedirect() the SPA is at: http://localhost:5173/?renew=iframe
  and renders: node-spa Not signed in. Log in with lanyard That link goes to a page this applic
  its own automatic renew: refused  (oidc-client-ts stops
    the renew timer on removeUser, so no iframe fires by itself)

  driving the same navigation the library would have — a real hidden iframe
  at the identical silent-renew URL, same browser, same cookie jar:
    Sec-Fetch-Dest: iframe
    Cookie: (no Cookie header — the logout cleared it)
    <- 302
    error: login_required
    error_description: prompt=none was sent and no lanyard_session cookie arrived with the request, so lanyard cannot tell who this browser is. The usual reason is a hidden iframe: lanyard's session cookie is SameSite=Lax, and a browser does not send it on a navigation from a site that is not lanyard's own. SameSite compares the host and ignores the port, so an app on http://localhost is same-site to an issuer on http://localhost and cross-site to one on http://127.0.0.1. The other two reasons a cookie goes missing are that this browser logged out of lanyard, and that lanyard restarted — sessions live in memory
